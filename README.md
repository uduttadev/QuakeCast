# Quakecast
## What is QuakeCast?
Quakecast is a seismic modeling software that utilizes machine learening to forecast seismic ground motion values (PGA and PGV) across stations in the Alaska area. It runs using a stack of Javascript and Python and is still under heavy development. 

## Installing
Deployment Instructions
- Clone the repo from https://github.com/uduttadev/QuakeCast
- Navigate to the directory you cloned to
- Install Node.JS and Python
- Install Node.JS dependencies (command: npm install)
- Install Python dependencies (command: pip install -r requirements.txt)
- Run the server (command: npm start)
- Access the application from your browser on localhost (http://localhost:3000)
